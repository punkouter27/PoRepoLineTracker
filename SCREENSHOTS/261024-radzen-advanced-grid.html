Repositories grid on the Radzen grid's own sort and filter (2026-10-24)

  • The Repositories table is a RadzenDataGrid. It already sorted from its column headers and filtered per column, so the hand-rolled sort dropdown and its direction button above the table were a second, worse way to do the same thing.
  • Gone from the table view: the "Total lines / Net change / Commits / Last commit / Status" select and the up-down arrow next to it. Clicking a column header sorts, and the header carries its own sort arrow.
  • Added to the grid: a filter on every column that has something to filter — Repository (matching owner/name), Total Lines, Net (30d), Commits (30d), Last commit and Status. Each header shows a funnel; the filter runs in the browser.
  • Mobile keeps its controls: below 768px the table is replaced by the card list, which is custom markup with no header row to click — so the select and the arrow stay there and drive the same sort state the grid's own header writes.
  • The search box stays everywhere: it is the URL's ?q=, so it must always be visible enough to be cleared.
